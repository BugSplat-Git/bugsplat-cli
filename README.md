# BugSplat CLI

`bugsplat` is a command line for [BugSplat](https://www.bugsplat.com) crash reporting, for people and coding agents: read crash reports and crash groups, find the symbol files a crash needs on your disk, and upload them.

It is in development and not released yet. The plan is in [issue 1](https://github.com/BugSplat-Git/bugsplat-cli/issues/1).

## Build

```bash
cargo build --release
./target/release/bugsplat --help
```
